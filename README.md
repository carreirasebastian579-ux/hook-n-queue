# Hook n' Queue

Página para encontrar con quién jugar League of Legends. Online en https://hooknqueue.com.

- `index.html`: la app completa (landing + app).
- `privacidad.html`: política de privacidad.
- `baja.html`: página para desactivar los avisos por mail.
- `base-de-datos.sql`: estructura de la base de datos (se pega en Supabase → SQL Editor).
- `iconos/`: íconos opcionales de posiciones (ver `iconos/LEEME.txt`).
- `robots.txt`, `sitemap.xml`, favicons y `og.png`: buscadores e imagen para compartir.

Base de datos, cuentas y chat: Supabase. Hosting: Vercel.
